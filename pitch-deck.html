TAPRUSH 06 / 12
FAIR PLAY

Four layers of anti-cheat.

When real money is on the line, fairness isn't optional.

RTT Tracking

Client measures round-trip time on every API call. Network latency is factored into reaction arbitration.

Early Tap = Forfeit

Tap before the DRAW signal? Automatic loss. The <80ms threshold catches bot scripts and auto-tappers.

Server Arbitration

Both clients submit timestamps. The backend Arbitrator service independently determines the winner. No client trust.

On-Chain Commits

Draw timing committed to Solana before the match. Post-match reveal proves the server didn't manipulate anything.
